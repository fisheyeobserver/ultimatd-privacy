Privacy Policy & User Data Disclosure

Last updated: May 2025

📜Overview

This Privacy Policy describes how LorelineSoftware collects, uses, and protects user data in the mobile application UltimaTD.

By using the application, you agree to the terms described in this policy.

📦Data We Collect

UltimaTD collects only the minimum data necessary for the game to function:

  • Email address (for account creation and authentication)
  • Display name / username
  • Google account profile information (if Google Sign-In is used)
  • Game progress data (gold, wood, building levels, completed maps)
  • Research and upgrade records
  • Timestamps for offline progress calculation
We do not access sensitive device data such as location, microphone, camera, or contacts.

🔧How We Use Your Data

Collected data is used solely for the following purposes:

  • Creating and verifying user accounts
  • Synchronizing game progress across devices
  • Maintaining account security via token refresh
  • Calculating offline production bonuses

We do not share your data with third parties or use it for advertising purposes.

☁️Data Storage

All user data is securely stored using Google Firebase infrastructure:

  • Firebase Authentication — Identity verification and session management
  • Cloud Firestore — Game save data storage

You can review Firebase's privacy policy at firebase.google.com/support/privacy.

🔑Google Sign-In

When signing in with Google, authentication is handled via an identity token provided by Google. We do not receive your Google password or full profile data.

Google's privacy policy: policies.google.com/privacy

👤Your Rights

Every user has the right to:

  • Request access to all data associated with their account
  • Request correction of inaccurate data
  • Request permanent deletion of their account and all associated data
  • Object to any data processing activities

To exercise these rights, please contact us at the address below.

🧒Children's Privacy

UltimaTD is not directed at children under the age of 13. We do not knowingly collect personal information from children under 13. If we become aware that such an account exists, we will promptly delete all associated data.

🔄Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected on this page with an updated date. Continued use of the application after changes constitutes acceptance of the revised policy.
